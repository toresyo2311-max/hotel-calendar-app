## 검증과 갱신 절차

`tools/master_db.py` 하나로 마스터 DB와 라이브 앱의 일치 여부를 확인합니다.

```bash
python3 tools/master_db.py verify    # data/master_db.json == index.html 인지 검사
python3 tools/master_db.py stats     # 수록 범위·호텔별 요금 표기 칸수 출력
python3 tools/master_db.py extract   # index.html -> data/master_db.json 재생성
python3 tools/master_db.py inject    # data/master_db.json -> index.html (DB·FLIGHTS만 교체)
```

`verify`는 탭별 호텔 수, ⑤ 브랜드 구성, 한·일 22곳의 현금·포인트 칸 수(6,800·6,629),
교차 탭 중복(alsoIn 없는 이름 중복), **② 중올플 289곳**(참여 287 · 권역 분포 116/137/36 · APC 칸 4,715 ·
12월 가능 210곳 · 현금 보유 40곳 / 미수집 249곳 · 비정상 고가 0 · public_id 중복 없음),
**③ 아코르 25곳**(신규 21곳 · 우한 124일·피스 263일·싼야 리만 357일·도쿄 362일·다롄 0일 · alsoIn 양방향 ·
SNU 43줄·8도시)·**출처 문구에 제3자 사이트 이름이 남아 있지 않은지**(금지어 4개는 `tools/master_db.py` 의
`FORBIDDEN` 에만 있고 문서·화면·JSON 에는 쓰지 않습니다)까지 검사합니다.

정상일 때 `verify` 출력:

```
VERIFY OK — master_db.json == index.html
  hotels 538  tabs {'lux': 162, 'china': 289, 'domestic': 25, 'marriott': 62}
  cells 196370  priced 79787  na 116583  stayplus 142  snu 43
  routes 32  deals 2201  window 2026-12-01~2027-11-30
  flights 당일치기 175건 · 패턴 12종
```

`verify` 는 항공 쪽도 검사합니다: 노선 32개(중국 신규 8개는 이름·건수까지 고정값 대조), 주말형 5패턴·당일치기 패턴(0박),
**months 2026-12~2027-11 12개**, **weeks 2026-12-03~2027-11-25 52주(7일 간격 연속, 주 시작=목요일)**,
기존 24개 노선의 2027년 1월 4주 × 5패턴 480칸 전수,
당일치기 `back == date`·노선별 `daytrip` 메타, 날짜 창(2026-12-01~2027-11-30) 안의 값,
**가격이 양의 정수인지(0원·추정 금지)**, `back == date + 박수`, (노선·출발일·패턴) 중복 없음,
월별 건수(2026-12 714 · 2027-01 704 · 2027-02 397 · 6~11월 131/129/47/35/43/1),
`noSale` 6건이 가격을 갖지 않는지, `bookingWindow.end = 2027-11-14` 까지입니다.

### 새 조사 결과를 넣는 순서

1. 조사 원문(md/pdf)에서 뽑은 요금을 **`data/master_db.json`의 해당 호텔 `rates`(과 필요하면
   `stayplus2`/`stayplus3`)에만** 반영합니다. 값이 없는 날은 `null`로 둡니다.
2. `counts`(요금 표기 칸수 등)와 `built`·`extended`·`sources`를 실제 값으로 고칩니다.
3. `python3 tools/master_db.py inject` — index.html의 `const DB`/`const FLIGHTS`만 다시 채웁니다.
   디자인·스크립트·탭 구조는 그대로이고, 자동 검증이 실패하면 원본으로 되돌립니다.
4. `python3 tools/master_db.py verify` 로 확인한 뒤 commit → push 합니다.

항공 특가는 md 한 장을 통째로 병합할 수 있습니다. 같은 (노선·출발일·패턴) 이 이미 있으면
기존 건(완본의 항공사·직항 정보)을 그대로 두고, 새 건만 더합니다.

```bash
python3 tools/merge_flights_batch.py ../data-sources/flights-2026-12/부산출발-항공특가-12월잔여-보완2차.md --dry-run   # 미리보기
python3 tools/merge_flights_batch.py ../data-sources/flights-2026-12/보고서1.md ../data-sources/flights-2026-12/보고서2.md --note "…KST ④ 항공 보완 반영"
python3 tools/master_db.py inject && python3 tools/master_db.py verify
```

보고서 md 형식은 세 가지(2차형 · 3차형 · 1차형)를 모두 읽습니다: 패턴 앞 원문자, 날짜/패턴 뒤
요일·박수, `MM/DD` 축약 날짜(노선은 `##`/`###` 헤딩, `PUS–XXX` 코드 동반 줄 포함), `가격표 실측` 표기,
`(가격표 …원)` 병기, `직항 최저 …원`(alt 로 살림). 같은 (노선·출발일·패턴) 이 이미 있으면
기본은 기존 건을 그대로 두고 항공사·직항·alt 가 비어 있을 때만 채웁니다. **더 새로운 실측으로
가격을 바꾸려면 `--replace-price`** 를 붙입니다(2027년 1월 보완1~3차 21조합, 2027년 2월 2~4주차 후쿠오카 15칸 갱신).

2027년 2월 2·3·4주차처럼 **한 주를 통째로 실측한 보고서**도 같은 도구가 읽습니다:
`2027-02-11 · 목~월 · 부산–후쿠오카(FUK) · 263,900원 · 에어부산 · 직항 1시간 (4박)` 형식,
`2/19 · ① · 부산–상하이 · …`(①~⑤ 는 ①금~일 ②토~월 ③목~일 ④금~월 ⑤목~월, 출발일 요일과 대조),
`2027-02-26 · 금~일·2박 · PUS–PVG · …` 형식입니다. `(직항 최저 …원)` 은 `alt` 로 살리고,
`(N박)`·`←이 노선 최저` 표시는 메모에서 빼며, 실측가가 기존 가격표 캐시값을 대신하면 `src` 표시를 지웁니다.

당일치기 보고서는 `tools/merge_daytrip.py` 로 넣습니다. 출발일의 요일에서 패턴(`목~목` …)을 만들고
`back=date`(0박)로 저장하며, 섹션 제목에 `불가`·`참고`가 있는 구간과 `가격 미표시` 줄은 넣지 않습니다.
`patterns`(kind=day)·주차 창(목~수)·노선별 `daytrip` 메타도 이 도구가 채웁니다.

```bash
python3 tools/merge_daytrip.py /workspace/data-sources/flights-2027-01/부산출발-항공특가-2027년1월-당일치기.md --dry-run
python3 tools/merge_daytrip.py … --note "…KST ④ 항공 당일치기 반영"
python3 tools/master_db.py refresh && python3 tools/master_db.py inject && python3 tools/master_db.py verify
```

`index.html`을 직접 손으로 고치지 마세요. 손으로 고쳤다면 `extract`로 마스터 DB를 다시 뜬 뒤
`git diff data/master_db.json` 으로 무엇이 바뀐지 확인하는 편이 안전합니다.

### 이전 파일 정리

- `data/parsed_rates.json`(2027-03~11 9개월 부분본, 9,712칸)은 **`data/master_db.json`에 완전히
  포함되어 삭제**했습니다. 두 파일이 서로 다른 시점을 담아 혼동을 만들던 문제를 없앴습니다.
  필요하면 `git show 34c41da:data/parsed_rates.json` 으로 꺼낼 수 있습니다.
- 앱은 여전히 `data/*.json`을 읽지 않습니다. 서버 없이 `index.html` 한 장으로 동작하며,
  마스터 DB는 **유실 방지용 원본 + 재빌드 기준**입니다.

## 유의사항

  `rates_krw`만 갈아끼우면 됩니다.

- 이비스 스타일 앰배서더 전주는 2027년 요금이 아직 열리지 않아 대부분 `NA`입니다.
