# 타 항공사 프로그램 — 부산↔옌타이(YNT)·난징(NKG) 공홈 비로그인 조회 실측 (2026-11-22 No.2)

에어프랑스/KLM(플라잉블루)은 다른 작업이 맡으므로 제외하고, 나머지 8개 프로그램 공식 홈페이지에서
**로그인 없이** 부산(PUS)↔옌타이(YNT)·난징(NKG) 마일리지 좌석이 조회되는지 직접 확인한 기록.

## 2. 델타 스카이마일즈 — 부산↔난징 실측 (병합 완료)

- 조회: `ko.delta.com` 비로그인, 편도, `마일로 쇼핑하기`, `가까운 날짜 함께 검색`.
- 화면 값 읽는 법(결과 목록 대조로 확인):
  - 이코노미 = **17,500 / 45,000**, 비즈니스(프레스티지) = **30,000 / 80,000**.
  - `가격 달력`은 그 날짜의 **최저 등급 값 하나**만 보여 준다. 그래서 `최저가` 필터를
    `Delta Main`과 `Delta First`로 각각 바꿔 두 번 읽고, 두 값을 합쳐 등급을 갈랐다.
    (예: 2026-12-14는 Main 30,000 + First 30,000 → 이코 없음·비즈 30,000. 결과 목록에서도
     KE1404+KE101 프레스티지 30,000 두 편성만 확인됨. 2026-12-15는 Main 17,500 + First 30,000)
  - 경유 횟수는 달력 오른쪽 요약("바로 1 경유")과 결과 목록으로 확인. 17,500·30,000·45,000·80,000
    네 단계 모두 **1회 경유** 편성이 확인됨(인천·하노이 등).
- 수집 구간: **2026-12-07 ~ 2027-10-16** (델타 판매 창). 가는 편 277일 · 오는 편 281일 = 558행.
  - 11-22~12-05와 12월·1월 일부(12-11~13, 12-25, 12-30~01-01, 01-03~04, 01-06~07, 01-09, 01-16,
    01-21, 01-23, 02-02, 02-04~06, 02-09~14, 04-09~11, 04-16~18, 04-23~25, 09-11, 09-13)는 그 달
    달력에서 좌석 없음(매진)으로 표시되어 행을 만들지 않았다.
- 대표값: 가는 편 2026-12-15 이코 17,500 / 비즈 30,000 · 2027-02-15 이코 17,500 / 비즈 30,000 ·
  2027-01-02 비즈 80,000만 · 2027-05-01 이코 45,000.

## 3. 델타 — 부산↔옌타이는 좌석 자체가 없음

- `PUS→YNT` 2026-12-14(±3일 묶음), `YNT→PUS` 같은 조건 모두
  "죄송합니다. 검색 기준에 맞는 결과가 없습니다 #ROF4002_404A".
- 델타는 옌타이를 **판매하지 않는 것**으로 보인다(마일이 아니라 편성 자체가 없음). 표본 1일이므로
  "이 날짜 기준 결과 없음"으로만 기록한다.

## 4. 동방항공(MU) 도시 13곳 — 조회 상태

- 델타 난징 편성의 실제 항공사는 **대한항공(KE)·베트남항공(VN)·샤먼항공(MF)** 이었고
  **동방항공(MU) 편성은 한 번도 나오지 않았다**(2026-12-15·12-14 결과 목록 직접 확인).
- 스마일즈에서는 PUS→YNT 12/14 **MU 1회 경유 280,400마일**이 실제로 표시됐다 → MU 노선이 뜨는
  비로그인 채널은 지금 확인된 곳 중 **스마일즈 하나**다.
- 13개 도시(PKX·TAO·CAN·XIY·XMN·DLC·CKG·TFU·WEH·HGH·SZX·SHE·HKG) 전수 조회는 **완료하지 못했다**.
  확인한 표본: 스마일즈 PUS→TAO 12/14 대한항공 직항 126,500마일. 나머지는 미확인으로 남긴다.

## 5. 다음에 이어서 할 때

- 델타는 `가격 달력` 두 번(Delta Main / Delta First) 읽기 + 한 달에 한 번 경유 횟수 표본 확인이면
  한 노선 1년이 12회 호출로 끝난다(연속 40회 넘기면 결과를 안 주는 전례가 있어 10~20회씩 끊는 편이 안전).
- 스마일즈는 `.../mfe/emissao-passagem/?originAirport=PUS&destinationAirport={코드}&departureDate={epoch ms}&tripType=2...`
  주소로 바로 결과 화면이 열린다(로그인 없이 카드 표시). 13개 도시 전수는 이 주소로 돌리는 것이 가장 빠르다.
- 로그인 벽 5곳(버진·유나이티드·에어로플랜·아시아마일즈·BA·JAL)은 계정 세션이 없으면 조회 불가.
