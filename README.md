# 🏨 호텔 요금 달력 웹앱 (hotel-calendar-app)

38개 호텔의 **2026-12-01 ~ 2027-11-30 (365일)** 최저가를 한 화면에서 보는 달력 웹앱입니다.
서버·로그인·DB가 필요 없는 **정적 HTML 한 장**이라 GitHub에 올린 뒤 Netlify로 자동 배포하면
링크 하나로 계속 열어볼 수 있습니다.

## 파일 구성

```
index.html              앱 본체. 데이터(DB)와 화면이 한 파일에 들어 있어 단독으로 열립니다.
data/parsed_rates.json  호텔별 날짜-요금 원본 DB. 앱 재빌드·갱신의 기준 자료.
netlify.toml            Netlify 배포 설정 (빌드 없음, 루트를 그대로 게시).
```

`index.html` 안의 `const DB = { ... }` 부분이 화면이 읽는 데이터입니다.
`data/parsed_rates.json`은 조사 결과를 호텔 ID별로 모아 둔 원본으로,
새 조사가 들어오면 이 DB에 합친 뒤 `index.html`의 `DB`를 다시 만들어 냅니다.

## 업데이트 방식

1. 새 요금 조사 결과를 `data/parsed_rates.json` 구조(`hotel id → {날짜: 요금}`)에 병합합니다.
2. 병합한 DB로 `index.html`의 `const DB`를 다시 채웁니다 (디자인·스크립트는 그대로).
3. 커밋 후 push하면 Netlify가 자동으로 재배포합니다. 별도 빌드 명령은 없습니다.

날짜별 값은 `null`(=`NA`)일 수 있습니다. `NA`는 조사 시점에 해당 날짜 요금이
공개되지 않았거나 예약이 열리지 않은 경우입니다.

## 유의사항

- HoteLux·FHR 24곳은 Google 달력 상한(2027-10-13) 이후 대부분 `NA`입니다.
- 소피텔·페어몬트 서울은 Stay Plus 만료(2027-09-30)로 10~11월은 일반 회원가만 표시됩니다.
- 이비스 스타일 앰배서더 전주는 2027년 요금이 아직 열리지 않아 대부분 `NA`입니다.
- 요금은 조사 시점의 1박 최저가이며, 세금·봉사료 포함 여부는 각 조사 원문 기준입니다.
  실제 예약 전에는 해당 호텔 공식 채널에서 다시 확인하세요.

## 배포

Netlify에서 이 저장소를 연결하면 `netlify.toml` 설정대로 **빌드 없이 루트 디렉터리**를 게시합니다.
`index.html`이 루트에 있으므로 사이트 최상위 주소에서 바로 앱이 열립니다.

비공개(private) 저장소로 운영할 경우 Netlify 쪽에서 이 저장소에 대한 GitHub 접근 권한을
한 번 허용해야 합니다.
