## 1. 화면 구성

| 자리 | 내용 |
| --- | --- |
| 상단 보기 전환 | 📅 통합 달력 · 🔁 대한항공 왕복 후보 · 🆕 대한항공 좌석 변동 · 🧮 대한항공 공제표 |

## 2. 값을 만들지 않는 규칙

- 원천이 알려 주지 않는 값은 화면에 만들지 않습니다 — 좌석 수량, 세금·수수료, **대한항공 직항·경유 편수**.
  그래서 「직항만」을 켜면 대한항공은 함께 빠집니다(원천에 직항 여부가 없음).
- 대한항공 필요 마일은 **공제표(편도 · 평수기)** 값입니다. 성수기 탑승일은 더 큽니다(시트·공제표 보기에 함께 적음).
- 프레스티지 승급(U)은 **마일 차감이 없는 승급**이라 최저 마일 계산에서 빼고 `승급`으로만 표시합니다.
- 미운항(부산발 직항 없음 5개 노선)·하계 미개시(2027-04 이후 6개 노선)·미수집은 서로 구분해 적습니다.
- 화면 문구에 제3자 조회 사이트 이름을 쓰지 않습니다(「조회 사이트」).

```
python3 tools/build_mileage_tab.py          # 마커 사이 블록만 교체 + 연결 고리 확인 + DATA_BUST 상향
python3 tools/build_mileage_tab.py --check  # 쓰지 않고 상태 확인
python3 tools/master_db.py verify           # VERIFY OK 확인
```
